Live, entirely-in-browser demo of a ~57M-parameter decoder-only transformer
pretrained from scratch in PyTorch. Runs via ONNX Runtime Web, no server
compute: the model, tokenizer, and generation loop all execute in your
browser.

Model: [hari-8/transformer-pretraining-from-scratch](https://huggingface.co/hari-8/transformer-pretraining-from-scratch).
Training code and full writeup:
[GitHub repo](https://github.com/Hariprashad-Ravikumar/transformer-pretraining-from-scratch).
